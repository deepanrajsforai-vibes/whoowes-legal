# whoowes-legal

Public legal pages for the WhoOwes app.

Hosted via Cloudflare Pages → `https://whoowes.pages.dev/`

## Pages

- `/` — Landing
- `/privacy` — Privacy Policy
- `/terms` — Terms of Service

## Editing

Plain static HTML + CSS. Edit the `.html` files directly. Cloudflare auto-deploys on push to `main`.
